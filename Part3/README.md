# Part 3 — Cross-Language Implementations

Two patterns are implemented in Java, Python, JavaScript, and C++:
- Strategy — Payment Module Selection
- Observer — Order Status SMS Notification

Each language subfolder contains production code, its test file, and a README with run instructions. Test logs are in `Part3/evidence/`. UML source and rendered diagrams are in `Part3/evidence/diagrams/`.

Canonical datasets are stored only in the team-level `data/` folder. Complexity values remain blank because they were not measured; no values have been inferred.
