# Part 1 — Pattern Discovery

This directory contains the selected source evidence, the Shopizer module dependency diagram (editable Mermaid source and PNG), the supporting report, and the canonical pattern inventory/count datasets copied here under the required Part 1 filenames.

- `patterns.csv`: copy of the canonical `data/patterns.csv`.
- `Pattern_count.csv`: copy of the canonical `data/pattern_counts.csv`.
- `Part1_prompt.txt` and `llm.csv`: recovered prompt record and provenance status. Historical raw outputs are not reconstructed.
- `code/original_source_evidence/`: selected baseline source excerpts; the complete baseline checkout is the submodule under `data/code/shopizer-3.2.7/`.
